Basic HTML Structure

An HTML document is structured with a doctype declaration, a head section, and a body section.

Code Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Document</title>
</head>
<body>

</body>
</html>
